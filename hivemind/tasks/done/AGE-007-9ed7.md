## Description
Update `/hv:task` SKILLs (claude and codex variants) to (1) consume the new `{tasks, deferred}` object from `hv run --ready-only`, and (2) add step 8.5 — a scope-drift gate that runs after coding-output verification. ## Changes to SKILL.md (claude + codex mirrors)
- Step 1 (fetch ready tasks): update text to expect `{tasks, deferred}` object instead of a bare array; mention the orchestrator should log deferred IDs and reasons for visibility
- Insert step 8.5 between current step 8 (verify coding output) and step 9 (run verification commands):
  - Compute `touched = git -C <worktree> diff <base>..HEAD --name-only`
  - For each path in `touched`, confirm it matches at least one entry in the task's declared scope
  - On unmatched paths: SendMessage to the worker with the out-of-scope list; instruct revert OR `hv task scope-add` if the new path legitimately belongs to this task
  - If `scope-add` is invoked, the orchestrator must verify disjointness against every in-flight peer's scope; on conflict, instruct revert (peer has priority)
  - Max 1 retry round; on exhaustion, block the task with `contract-drift: out-of-scope writes`
- Parallel-mode specifics: add one line noting that scope-conflict deferrals are automatic and the loser becomes the next round's anchor by priority
- Important Rules: add "NEVER let a worker write outside declared scope without explicit `hv task scope-add` and orchestrator re-check"
