## Public API
- `normalize(raw: list[str] | None) -> list[str]` — strip whitespace, dedupe, preserve order
- `is_solo(scope: list[str]) -> bool` — True when scope is None/empty or contains `"*"`
- `conflicts(a: list[str], b: list[str]) -> str | None` — return first conflicting entry from `a` if any, else None
- `overlap(a: list[str], b: list[str]) -> list[str]` — return every conflicting entry pair detected
- `pack_non_conflicting(candidates: list[tuple[str, list[str]]], limit: int) -> tuple[list[str], list[ConflictReport]]` — greedy packing, returns selected ids + deferred reports

## Glob matcher
- Path globs support `*` (matches one segment, no `/`) and `**` (matches zero or more segments)
- Case-sensitive
- Namespaced tags (`manifest:`, `harness:`, `config:`) match only within the same namespace via the same glob rules applied to the value part
- Path globs and namespaced tags never conflict
