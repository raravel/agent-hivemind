## Description
Umbrella epic for scope-aware parallel scheduling in `/hv:task --parallel`. Adds a declared `scope` field to leaf tasks, makes `hv run --ready-only` pack a disjoint batch, and gates worker output by scope at execution time. See the feature spec for the full rationale and design.
