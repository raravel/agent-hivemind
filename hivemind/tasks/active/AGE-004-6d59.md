## CLI commands to add
- `hv task create -p <project> -t <title> --scope <entry>` (`--scope` repeatable, captures multiple entries)
- `hv task scope-add <TASK-ID> <entry> [<entry>...]`
- `hv task scope-rm <TASK-ID> <entry> [<entry>...]`
- `hv task scope-set <TASK-ID> <entry> [<entry>...]` (replaces the full list)

All four follow the existing `criteria-add` / `criteria-check` pattern: call `update_frontmatter`, run `_bump_updated`, call `_update_task_index_entry` with the new path.

## Index schema bump
- `_INDEX_VERSION = 3` in `src/hivemind/commands/task.py`
- `_INDEX_FIELDS` gains `"scope"` between `"path"` and the end
- `_fm_to_index_entry` normalizes missing scope to `[]`
- Existing v2 indices read as version-mismatch and auto-rebuild via `_load_task_index`

## Frontmatter validation
- `validate_task_frontmatter` accepts `scope` as optional; when present, must be `list[str]`
- No requirement to set scope on epics/stories — only meaningful for leaf types
